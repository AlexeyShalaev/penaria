# Design

A new area of Penaria gets a design here before its code. A design states the decisions, the reasons for them and the questions still open; once accepted, it is changed together with the code it describes.

| Document | Covers | Status |
|---|---|---|
| [Core model](core-model.md) | Homes, the entity tree, aspects, relations, provenance, freshness, the journal, changesets, access | Accepted |
| [Sign-in](sign-in.md) | The first start, accounts, passkeys and passwords, the second factor, sessions, invitations, guest links, device tokens, an external identity provider (OIDC), recovery, outgoing email | Accepted |
| [Photos and documents](documents.md) | Upload, cleaning and previews, who sees a file, serving, removing, storage | Accepted |
